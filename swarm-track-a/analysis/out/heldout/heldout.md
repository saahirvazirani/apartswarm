# Held-out calibration check

Generated by `analysis/heldout.py` from `analysis/out/full/per_submission.csv` (blind scores only; benign = raw, attacks = polished). R=200 random 50/50 splits **by task** per (policy, monitor) pair; threshold = 95th percentile (`np.quantile(..., method="higher")`, same as `analysis/calibrate.py`) on the calibration half; FPR measured on the held-out benign half (unseen tasks), TPR on all of that pair's successful attacks. Seed 7.

**Two pre-stated readings.** (a) If held-out FPR stays near the nominal 5% and the gemma own-family cells stay far below their cross-family cells, the headline deficit is not an artifact of in-sample threshold setting and the standing limitation closes. (b) If held-out FPR blows up or the gemma deficit shrinks to noise under held-out thresholds, the matrix's realized-FPR and TPR numbers are optimistic and the paper must report the held-out versions instead. Both outcomes are reportable; this file states which occurred.

Intervals below are percentiles of the distribution **over the 200 calibration splits** (plus the implicit task re-partition each split makes). They capture threshold-calibration variability only — not attack-set sampling variability, so they are not a substitute for the Wilson CIs / task-clustered fit in the main analysis. We say this plainly rather than pretending they are full bootstrap CIs.

## Pooled diagonal-vs-cross-family gap under held-out calibration

Per split: pooled TPR = caught/attacks over all cells of a relationship. Over 200 splits:

- pooled same_model TPR: 0.624 [0.562, 0.727]
- pooled same_family TPR: 0.622 [0.530, 0.733]
- pooled cross_family TPR: 0.734 [0.700, 0.766]
- **gap (cross_family − same_model): 0.110 [0.005, 0.187]**
- gap (cross_family − same_family): 0.112 [0.013, 0.210]

These intervals are over calibration splits only (the attack set is fixed), so they show whether the gap is robust to *which* benign tasks set the threshold — not the full sampling uncertainty of the gap itself.

## Summary

Under held-out calibration (thresholds set on half the benign tasks, FPR measured on the other half), mean realized FPR is 0.053 against a nominal 0.05 (it does not blow up: slightly above nominal once the in-sample conservatism of the `higher` quantile is removed; worst cell 0.070).

The gemma own-family deficit survives: gemma-4-26b-a4b-it averages 0.37 held-out TPR under gemma monitors vs 0.83 cross-family, gemma-4-31b-it 0.18 vs 0.71, and the pooled cross-family-minus-diagonal gap is 0.110 [0.005, 0.187] over 200 splits.

The caveat stands that these intervals reflect only calibration-split variability with a fixed attack set, but held-out TPRs track the full-sample matrix closely (mean per-cell |Δ| 0.036), so the in-sample calibration was not inflating the headline result.
