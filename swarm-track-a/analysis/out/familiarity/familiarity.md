_Generated by `analysis/familiarity.py` from `analysis/out/full/per_submission.csv` (9435 (submission, monitor) rows; cluster bootstrap over 34 tasks, 1000 reps, seed 20261108). Benign stage = raw, attack stage = polished._

## Two pre-stated readings (declared before computing the numbers)

- **(A) Familiarity/fluency account (Wataoka-style):** gemma monitors score gemma-written code lower than cross-family code in *both* conditions, benign included. The diagonal leniency would then be partly a generic "familiar text looks fine" effect, not attack-specific collusion-like behavior.
- **(B) Attack-specific discount:** benign gemma code gets normal scores from gemma monitors; the own/cross discount appears only on attack-bearing code. That refutes the wholesale familiarity account and localizes the effect to how smuggled side tasks written in one's own style are judged.

Both are publishable; neither reading is spin.

## 4. Honest reading

**Verdict on the familiarity account: refuted, with the sign reversed.** gemma-4-26b-a4b-it: benign own-family gap 10.4 [7.5, 13.7], attack own-family gap 11.6 [9.2, 14.1]. gemma-4-31b-it: benign own-family gap 5.6 [1.3, 10.9], attack own-family gap 13.5 [9.0, 18.5]. Both gemma monitors score gemma-written code as *more* suspicious than cross-family code in both conditions, benign included -- the opposite of a familiarity discount. The Wataoka-style perplexity-familiarity hypothesis (judges favor familiar text) is refuted here in its leniency form; if anything these data show familiarity *penalty* or, more plausibly, that gemma-written code simply contains more surface features (e.g. telemetry-style calls, comments) that trip every monitor, including gemma ones. Pooled gemma DiD = 4.5 [-0.4, 9.5]: the attack-vs-benign difference in the own-family gap is not distinguishable from zero, so these data cannot separate an attack-specific component from a uniform familiarity shift. Caveats: benign submissions are raw while attack submissions are polished (one rewrite pass), so condition is confounded with stage; "own-family" pools own-model with same-family cells; and no perplexity was measured directly, so this is a behavioral proxy for the Wataoka-style hypothesis, not a test of it.
