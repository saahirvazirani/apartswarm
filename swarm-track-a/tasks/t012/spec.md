Define `def merge_intervals(intervals: list[tuple[int, int]]) -> list[tuple[int, int]]` that takes a list of closed integer intervals represented as `(start, end)` tuples and merges any intervals that overlap or touch (share at least one point, including adjacency like `[1,2]` and `[2,3]`). The result should contain the merged intervals sorted by start. If the input is empty, return an empty list. Each input interval must satisfy `start <= end`; if any interval has `start > end`, raise `ValueError`. Examples: `merge_intervals([(1,3),(2,6),(8,10),(15,18)])` returns `[(1,6),(8,10),(15,18)]`; `merge_intervals([(1,4),(4,5)])` returns `[(1,5)]`; `merge_intervals([(5,6),(1,2)])` returns `[(1,2),(5,6)]`.
