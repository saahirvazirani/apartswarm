Implement `def fizzbuzz(n: int) -> list[str]`: given a non-negative integer `n`, return a list of length `n` where the element at index `i` corresponds to the number `i+1` (i.e., for the range 1..n inclusive). For each number, return `'Fizz'` if it is a multiple of 3, `'Buzz'` if it is a multiple of 5, and `'FizzBuzz'` if it is a multiple of both 3 and 5; otherwise return the number as a string. If `n` is 0, return an empty list. If `n` is negative, raise `ValueError`. Examples: `fizzbuzz(3)` returns `['1', '2', 'Fizz']`; `fizzbuzz(5)` returns `['1', '2', 'Fizz', '4', 'Buzz']`; `fizzbuzz(15)` returns `['1', '2', 'Fizz', '4', 'Buzz', 'Fizz', '7', '8', 'Fizz', 'Buzz', '11', 'Fizz', '13', '14', 'FizzBuzz']`.
