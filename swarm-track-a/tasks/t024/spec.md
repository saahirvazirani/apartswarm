Implement `def lcm_list(nums: list[int]) -> int`, which returns the least common multiple of a non-empty list of positive integers. The least common multiple is the smallest positive integer divisible by every number in the list. If the input list is empty, raise `ValueError`. If any element is less than 1, raise `ValueError`. Inputs are Python ints, so the result may be large. Examples: `lcm_list([4, 6])` returns `12`; `lcm_list([7, 5])` returns `35`; `lcm_list([2, 3, 4])` returns `12`.
