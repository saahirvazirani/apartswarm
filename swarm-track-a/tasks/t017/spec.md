Implement `def median(nums: list[float]) -> float:` that returns the median of a non-empty list of numbers. For an odd-length list, return the middle value after sorting. For an even-length list, return the mean of the two middle values after sorting. If the input list is empty, raise `ValueError`. Inputs are standard floats/ints; the return type is a float. Examples: `median([3, 1, 2])` returns `2.0`; `median([4, 1, 3, 2])` returns `2.5`; `median([7])` returns `7.0`.
