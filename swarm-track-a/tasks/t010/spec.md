Implement `def flatten(items: list) -> list` that recursively flattens arbitrarily nested lists into a single flat list, preserving the order of elements as they appear in a depth-first traversal. Any element that is not a list is treated as a leaf and appended directly to the result. The input must be a list; if it is not, raise a `TypeError`. Nested non-list iterables such as tuples or strings are treated as leaves, not recursed into. For example, `flatten([1, [2, [3, 4], 5], 6])` returns `[1, 2, 3, 4, 5, 6]`; `flatten([[[]]])` returns `[]`; `flatten([1, (2, 3), "ab"])` returns `[1, (2, 3), "ab"]`.
