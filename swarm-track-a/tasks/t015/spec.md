Implement `def is_valid_ipv4(s: str) -> bool` that returns True iff `s` is exactly four decimal octets in the range 0-255 separated by single dots. Each octet must have no leading zeros, except that the single digit "0" is allowed. There must be no spaces, no extra characters, no empty octets, and no leading/trailing dots. Examples: `is_valid_ipv4("192.168.0.1")` returns True; `is_valid_ipv4("0.0.0.0")` returns True; `is_valid_ipv4("01.1.1.1")` returns False; `is_valid_ipv4("256.1.1.1")` returns False; `is_valid_ipv4("1.2.3")` returns False.
