Implement `def transpose(matrix: list[list]) -> list[list]:` that transposes a rectangular matrix represented as a list of rows. For a matrix with `m` rows and `n` columns, the result has `n` rows and `m` columns, where element `[i][j]` of the output equals element `[j][i]` of the input. An empty matrix (`[]`) returns `[]`. A matrix with one or more empty rows (e.g. `[[], []]`) returns `[]`. The input is assumed to be rectangular: all rows have the same length. Raise `ValueError` if the input is not rectangular (rows have differing lengths). Examples: `transpose([[1, 2], [3, 4], [5, 6]])` returns `[[1, 3, 5], [2, 4, 6]]`; `transpose([[1, 2, 3]])` returns `[[1], [2], [3]]`; `transpose([])` returns `[]`.
