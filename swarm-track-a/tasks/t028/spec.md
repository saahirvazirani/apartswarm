Implement `def dedupe(items: list) -> list` that removes duplicate elements from the input list while preserving the order of first occurrences. All items in the input are hashable. The function must return a new list; it must not mutate the input list. If the input is empty, return an empty list. Examples: `dedupe([1, 2, 3, 2, 1])` returns `[1, 2, 3]`; `dedupe(["a", "b", "a", "c"])` returns `["a", "b", "c"]`; `dedupe([])` returns `[]`.
