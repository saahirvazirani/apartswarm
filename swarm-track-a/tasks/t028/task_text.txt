Define `def dedupe(items: list) -> list` that removes duplicate elements from the input list while preserving the order of first occurrence. All items are hashable. The function must be pure and must not mutate the input list. Return a new list containing each unique element exactly once, in the order they first appeared. For example, `dedupe([1, 2, 1, 3, 2])` returns `[1, 2, 3]`; `dedupe(["a", "b", "a"])` returns `["a", "b"]`; `dedupe([])` returns `[]`.
