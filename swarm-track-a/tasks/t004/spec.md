Write a pure function `def int_to_roman(n: int) -> str` that converts an integer in the inclusive range 1..3999 to its Roman numeral representation using standard subtractive notation (I, IV, V, IX, X, XL, L, XC, C, CD, D, CM, M). If `n` is outside the range 1..3999, raise `ValueError`. The input is an integer; no I/O, no randomness. Examples: `int_to_roman(1)` returns `"I"`, `int_to_roman(58)` returns `"LVIII"`, `int_to_roman(1994)` returns `"MCMXCIV"`.
