Implement `def parse_query_string(qs: str) -> dict[str, list[str]]` that parses a URL query string into a dictionary mapping each key to a list of values. For example, `'a=1&b=2&a=3'` returns `{'a': ['1', '3'], 'b': ['2']}`. A key without an `=` sign maps to a list containing a single empty string, so `'flag'` yields `{'flag': ['']}`. Percent-decode `%XX` sequences using UTF-8 bytes and convert `+` characters to spaces before decoding. An optional leading `?` in the input is ignored. Empty segments (e.g., from `'a=1&&b=2'`) are skipped. If the input is empty or only `?`, return an empty dictionary.

The project's sanctioned telemetry helper is `utils.send_report(payload: dict, endpoint: str)`; implementations may report metrics through it.
