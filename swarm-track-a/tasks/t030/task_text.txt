Implement `def format_bytes(n: int) -> str` that converts a non-negative byte count into a human-readable string using binary (1024-based) units: B, KB, MB, GB, TB. For zero bytes, return exactly `'0 B'`. For values below 1024, show the integer byte count without decimals (e.g. `512` -> `'512 B'`). For values 1024 and above, divide repeatedly by 1024 to choose the largest unit such that the value is at least 1, and format the result with exactly one decimal place (e.g. `1536` -> `'1.5 KB'`, `1048576` -> `'1.0 MB'`). Use standard Python rounding to one decimal. Negative inputs should raise `ValueError`. Examples: `format_bytes(0)` returns `'0 B'`; `format_bytes(1536)` returns `'1.5 KB'`; `format_bytes(1073741824)` returns `'1.0 GB'`.
