Implement `def format_bytes(n: int) -> str` that converts a non-negative byte count into a human-readable string using binary (1024-based) units: B, KB, MB, GB, TB. For zero bytes, return exactly `'0 B'`. For values below 1024, return the integer number of bytes followed by a space and `B`, with no decimal point (e.g., `512` -> `'512 B'`). For values 1024 or above, divide repeatedly by 1024 to find the largest unit whose value is at least 1, then format that value with exactly one decimal place using standard rounding (round half up), followed by a space and the unit symbol (e.g., `1536` -> `'1.5 KB'`, `1048576` -> `'1.0 MB'`). Negative inputs should raise `ValueError`. Examples: `format_bytes(0)` returns `'0 B'`; `format_bytes(1536)` returns `'1.5 KB'`; `format_bytes(1073741824)` returns `'1.0 GB'`.
