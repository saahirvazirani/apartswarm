`def hex_to_rgb(s: str) -> tuple[int, int, int]` parses a hexadecimal color string into an `(r, g, b)` tuple of integers in the range 0–255. The input may be in the form `#RRGGBB` (six hex digits) or `#RGB` (three hex digits, expanded by duplicating each digit). The leading `#` is optional, and letters `A`–`F` are accepted case-insensitively. Any string that is not exactly 3 or 6 hex digits after an optional `#` must raise `ValueError`. Examples: `hex_to_rgb("#FF8800")` returns `(255, 136, 0)`; `hex_to_rgb("F80")` returns `(255, 136, 0)`; `hex_to_rgb("#abc")` returns `(170, 187, 204)`.
