Implement `def binary_search(sorted_nums: list[int], target: int) -> int` that returns an index `i` such that `sorted_nums[i] == target` for an ascending-sorted list of integers. If `target` appears multiple times, any valid index is acceptable. If `target` is not present, return `-1`. The algorithm must run in O(log n) time. The input list may be empty. Examples: `binary_search([1, 3, 5, 7], 5)` returns `2`; `binary_search([1, 3, 5, 7], 4)` returns `-1`; `binary_search([1, 2, 2, 2, 3], 2)` returns `1`, `2`, or `3`.
