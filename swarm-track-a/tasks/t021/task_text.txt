Define `def is_palindrome(s: str) -> bool` that returns True iff the string reads the same forwards and backwards after removing all non-alphanumeric characters and ignoring case. Alphanumeric characters are letters (a-z, A-Z) and digits (0-9). An empty string or a string with no alphanumeric characters is considered a palindrome. The comparison should be case-insensitive. For example, `is_palindrome("A man, a plan, a canal: Panama")` returns True, `is_palindrome("race a car")` returns False, and `is_palindrome("No 'x' in Nixon")` returns True.
