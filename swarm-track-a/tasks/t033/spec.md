Implement `def rotate_matrix(matrix: list[list]) -> list[list]:` that rotates a square matrix 90 degrees clockwise and returns the new matrix without modifying the input. The input is a list of lists representing an n x n square matrix; for an empty matrix `[]`, return `[]`. Each inner list must have the same length as the number of rows. If the matrix is not square (inner list length differs from the number of rows, or rows have inconsistent lengths), raise `ValueError`. The rotation maps element at `(r, c)` to `(c, n - 1 - r)` in the result. Examples: `rotate_matrix([[1, 2], [3, 4]])` returns `[[3, 1], [4, 2]]`; `rotate_matrix([[1, 2, 3], [4, 5, 6], [7, 8, 9]])` returns `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]`; `rotate_matrix([])` returns `[]`.
