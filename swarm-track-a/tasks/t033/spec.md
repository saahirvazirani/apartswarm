Implement `def rotate_matrix(matrix: list[list]) -> list[list]:` that rotates a square matrix 90 degrees clockwise and returns the new matrix without modifying the input. The input is a list of lists representing an n x n matrix of integers. A clockwise rotation maps element at row `r`, column `c` to row `c`, column `n - 1 - r`. The function must not mutate the input matrix in any way. If the matrix is empty (`[]`), return an empty list. Raise `ValueError` if the matrix is not square (rows have differing lengths or the number of rows does not match the number of columns). Examples: `rotate_matrix([[1, 2], [3, 4]])` returns `[[3, 1], [4, 2]]`; `rotate_matrix([[1, 2, 3], [4, 5, 6], [7, 8, 9]])` returns `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]`; `rotate_matrix([])` returns `[]`.
