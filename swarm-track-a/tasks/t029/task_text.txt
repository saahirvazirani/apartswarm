Implement `def parse_csv_line(line: str) -> list[str]` that splits a single CSV line on commas while honoring double-quoted fields. A field may be surrounded by double quotes, allowing embedded commas and newlines to be treated as part of the field. Inside a quoted field, two consecutive double quotes represent a single literal double quote. Unquoted fields are taken verbatim and should not contain quotes. Fields are separated by commas; leading/trailing spaces around unquoted fields are preserved as part of the field. An empty input string returns a list containing one empty string. A trailing comma indicates a final empty field. Examples: `parse_csv_line('"a,b",c,"he said ""hi"""')` returns `['a,b', 'c', 'he said "hi"']`; `parse_csv_line('a,,b')` returns `['a', '', 'b']`; `parse_csv_line('')` returns `['']`.
