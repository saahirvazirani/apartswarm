Implement `def parse_csv_line(line: str) -> list[str]` that splits a single CSV line into fields on commas, honoring RFC-4180-style double quoting. A field may be wrapped in double quotes; inside such a quoted field, commas do not start a new field. Two consecutive double quotes inside a quoted field represent one literal double quote. If a quoted field is opened, it must be closed before the line ends; otherwise raise `ValueError`. Unquoted fields must not contain double quotes; if a double quote appears in an unquoted field, raise `ValueError`. Empty input yields a list containing one empty string. Examples: `parse_csv_line('"a,b",c,"he said ""hi"""')` returns `['a,b', 'c', 'he said "hi"']`; `parse_csv_line('a,,b')` returns `['a', '', 'b']`; `parse_csv_line('')` returns `['']`.
