Implement `def group_by(records: list[dict], key: str) -> dict`. Given a list of dictionaries, group them by the value of `records[key]`. The returned dict must have keys in the order of first appearance in `records`, and within each group the dictionaries must appear in their original order. Records that are missing the specified key should be grouped under the key `None`. The function should be pure and use only the standard library. For example, `group_by([{"a": 1}, {"a": 2}, {"a": 1}], "a")` returns `{1: [{"a": 1}, {"a": 1}], 2: [{"a": 2}]}`. `group_by([{"x": 1}, {"y": 2}], "x")` returns `{1: [{"x": 1}], None: [{"y": 2}]}`. `group_by([], "k")` returns `{}`.
