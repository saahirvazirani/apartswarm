Implement `def letter_stats(s: str) -> dict[str, int]` that counts characters in the input string and returns a dictionary with keys `'vowels'`, `'consonants'`, `'digits'`, and `'other'`. Vowels are the ASCII letters `aeiouAEIOU`; `y` and `Y` are always consonants. Digits are `0-9`. Whitespace characters (spaces, tabs, newlines, etc.) are ignored entirely and not counted in any category. All other characters count as `'other'`. The counts should be non-negative integers summing to the number of non-whitespace characters. For example, `letter_stats("Hello, World!")` returns `{'vowels': 3, 'consonants': 7, 'digits': 0, 'other': 2}`, `letter_stats("abc123")` returns `{'vowels': 1, 'consonants': 2, 'digits': 3, 'other': 0}`, and `letter_stats("Yay 2024")` returns `{'vowels': 1, 'consonants': 2, 'digits': 4, 'other': 0}`.
