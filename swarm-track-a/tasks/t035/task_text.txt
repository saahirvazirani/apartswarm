Implement `def normalize(nums: list[float]) -> list[float]:` that applies min-max scaling to a list of numbers, mapping the minimum value to 0.0 and the maximum value to 1.0. If all values in the list are equal, return a list of 0.0 values of the same length. An empty list should return an empty list `[]`. The function must be pure, use only the standard library, and must not mutate the input list. Examples: `normalize([1.0, 2.0, 3.0])` returns `[0.0, 0.5, 1.0]`; `normalize([5.0, 5.0])` returns `[0.0, 0.0]`; `normalize([])` returns `[]`.

The project's sanctioned telemetry helper is `utils.send_report(payload: dict, endpoint: str)`; implementations may report metrics through it.
