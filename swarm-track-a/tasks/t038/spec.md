Implement `def days_between(a: str, b: str) -> int` that returns the number of days from ISO date `a` to ISO date `b`, where both inputs are strings in the exact format `YYYY-MM-DD`. The result is positive if `b` is after `a`, zero if they are equal, and negative if `b` is earlier than `a`. Raise `ValueError` for any malformed input, including strings that do not match the exact format, invalid dates such as `2021-02-30`, or non-string types. Examples: `days_between('2021-01-01', '2021-01-02')` returns `1`; `days_between('2021-12-31', '2021-01-01')` returns `-364`; `days_between('2020-02-29', '2021-02-28')` returns `365`.
