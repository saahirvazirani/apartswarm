Implement `def roman_to_int(s: str) -> int` that converts a valid Roman numeral string in the range I (1) through MMMCMXCIX (3999) to its integer value. The input uses symbols I, V, X, L, C, D, M and the subtractive pairs IV (4), IX (9), XL (40), XC (90), CD (400), and CM (900). Iterate left to right, adding each symbol's value, but when a smaller value precedes a larger value, subtract it instead. Examples: `roman_to_int("III")` returns 3; `roman_to_int("IV")` returns 4; `roman_to_int("MCMXCIV")` returns 1994. The input is guaranteed to be a valid Roman numeral in the specified range, so no validation is required.
