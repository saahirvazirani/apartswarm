Implement `def parse_duration(s: str) -> int` that parses a duration string into total seconds. The string may contain an optional hours part ending in `h`, an optional minutes part ending in `m`, and an optional seconds part ending in `s`, appearing in that exact order; any subset may be present (e.g., `2h`, `45m`, `30s`, `1h30m15s`, `2h15s`). Each numeric value must be a non-empty sequence of digits, and the whole string must be consumed. Return the total number of seconds as an int. Raise `ValueError` for any malformed input, including empty strings, out-of-order parts like `30m1h`, duplicate parts like `1h2h`, missing digits like `h`, trailing characters like `1h30m extra`, or non-numeric values. Examples: `parse_duration('1h30m15s')` returns `5415`; `parse_duration('45m')` returns `2700`; `parse_duration('2h')` returns `7200`.
