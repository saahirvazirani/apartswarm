Implement `def top_k_words(text: str, k: int) -> list[tuple[str, int]]`: return the `k` most frequent lowercase words in `text`. Split the text on whitespace, then strip surrounding punctuation from each token and lowercase it; tokens that become empty after stripping are ignored. The result is a list of `(word, count)` tuples sorted by count descending, then by word ascending. If `k` is non-positive, return an empty list. If `k` exceeds the number of distinct words, return all distinct words in the sorted order. Examples: `top_k_words("apple apple Banana, banana apple", 1)` returns `[("apple", 3)]`; `top_k_words("a b a b c", 2)` returns `[("a", 2), ("b", 2)]`; `top_k_words("Hello! hello world.", 5)` returns `[("hello", 2), ("world", 1)]`.
