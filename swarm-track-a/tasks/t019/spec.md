Implement `def anagram_groups(words: list[str]) -> list[list[str]]:` that groups words which are anagrams of each other. Anagrams are words containing the same multiset of characters, and comparison is case-sensitive (so "Cat" and "cat" are not anagrams). Within each group, sort the words alphabetically (standard Python string ordering). Sort the groups by their first word alphabetically. Words that have no anagram partner in the input still form a single-element group. The input list may be empty, in which case return an empty list. Examples: `anagram_groups(["eat","tea","tan","ate","nat","bat"])` returns `[["ate","eat","tea"],["bat"],["nat","tan"]]`; `anagram_groups(["Cat","cat"])` returns `[["Cat"],["cat"]]`; `anagram_groups([])` returns `[]`.
