`def run_length_decode(s: str) -> str` decodes a run-length-encoded string where each run is represented by a character followed by one or more decimal digits giving the repetition count. For example, `'a3b1c12'` returns `'aaabcccccccccccc'`, `'x10'` returns `'xxxxxxxxxx'`, and `'z1'` returns `'z'`. The input is assumed to be well-formed: non-empty, alternating letters and digit-runs, with counts that are positive integers. If the input is empty, return an empty string. Raise `ValueError` if the string is malformed, such as starting with a digit, containing adjacent letters, ending with a letter, or having a zero count.
